# Alternative Ventures

Site institucional + AV OS (Founder Command Center) da Alternative Ventures.

## Estrutura

- `site/` — site público e área privada (`/login` e `/office`)
- `site/manifesto/` — manifesto
- `site/dev/` — Alternative Digital Products Studio
- `netlify/functions/` — autenticação e APIs do AV OS
- `infra/` — schema e documentação de infraestrutura

O deploy de produção é feito pelo Netlify a partir deste repositório.
